_`etl 20.47.1`
---------------

**Why it is here.** Provenance for the parts of a motor controller that are easy to get subtly wrong and cheap to get from a tested, fielded embedded library: CRC (a wrong polynomial is silent), bit-stream packing for non-byte-aligned encoder frames, byte order, and fixed-capacity text formatting without allocation.

**What it buys.** A second, independently written implementation to compare against our own on every push (the cross-check cases), and a tested bit manipulator behind the compiled face. It is evidence, not convenience: 'our CRC agrees with ETL byte for byte over 0..64 byte frames' is a sentence a reviewer can check.

**Verdict.** INTERNAL ONLY. Every candidate header costs a consumer 7x-34x the price of the whole foc include face, so ETL may not appear on any public header. It is a :code:`cpp` bucket (conan) dependency, which is visible to the recipe, while :code:`include/**` stays free of it: the include face is what a consumer actually pays for.

it up here. "Behaviour" means writing our own test for what the other project guarantees;
"code" means copying, and it is only available under a permissive licence.

Working rules
-------------

**Two ways to integrate, and only one is about code**

**Behaviour integration, always allowed.** Write our own test that encodes what the other project guarantees, then satisfy it. No licence question arises, and the test is the artefact that survives.

**Code integration, permissive licences only.** Copy, keep the notice, extend :code:`NOTICE`, and let :code:`gates.py license` keep everyone honest. A vendored subtree that is legitimately copyleft needs a scope line in :code:`.github/misc/.license-guard.txt` and an entry in :code:`NOTICE`; the library default stays permissive.

**How to verify a licence: clone it, do not fetch it**

A web fetch cannot extract a plain-text :code:`LICENSE`, and a clone also pins the exact commit the conclusion rests on — which a web page never does. :code:`workspace/` is git-ignored, so the reference copy never reaches a commit, but the conclusion and the commit hash do.

**Hardware is not code**

Driving hardware designed for another project needs no licence at all, and it is the cheapest real integration available: implement the five HAL interfaces (:code:`Pwm`, :code:`CurrentSense`, :code:`PositionSensor`, :code:`DcLink`, :code:`Clock`) for that board and the library serves it.
